I analysed internal data requests from 2025 to 2026 to find the ones that kept coming back. I then built automated data extract reports in SQL and configured Azure Databricks jobs to run them daily and monthly, which reduced the effort spent resolving tickets.

Alongside this, I handled exploratory data requests in SQL and reported cases of poor data quality or non-compliance with intended formats, to support data governance.
