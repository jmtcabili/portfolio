I built a web-based point-of-sale system for Fun For Kids Corporation with Next.js, Tailwind CSS and Supabase. It manages stroller and wheelchair rentals across 13 kiosks and improved the efficiency of in-store operations.

For the owners, I built an interactive dashboard with Chart.js. It shows overall sales trends and branch performance, identifies the most-rented cart types and tracks employee attendance.
